# Interpreter in Progress

Building an interpreter from scratch following the concepts in [*Crafting Interpreters*](https://craftinginterpreters.com/) by Robert Nystrom.

## Status
 **Under Active Development** — Just getting started! 

## Tech Stack
* **Language:** *(Java for part 1 of the book and C for part 2)*

## Goals
* Build a tree-walk interpreter (jlox)
* Build a bytecode virtual machine (clox)
* Deep dive into lexical analysis, parsing, evaluation, and memory management.
